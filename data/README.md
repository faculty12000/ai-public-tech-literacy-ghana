# Data

This directory intentionally contains no participant-level data.

If data are collected for this study, store identifiable information outside the public repository in an access-controlled location approved by the relevant ethics process. Publish only aggregated, de-identified outputs after confirming that small cells, quotations, and combinations of attributes cannot identify participants or communities.

Recommended public outputs include a data dictionary, a codebook, an anonymised analysis dataset only where consent and disclosure review permit it, and reproducible analysis code with all credentials and sensitive paths removed.
